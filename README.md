# faroedu.com

One self-contained page. No build step.

- index.html: the whole site (markup, CSS, JS, photos inlined as data URIs, ~2.2 MB).
- netlify.toml: publish dir + security headers.
- The demo form posts to Netlify Forms (name="demo-request"). Enable form detection in the Netlify project and set a notification email.

## Deploy

Netlify project incomparable-eclair-84f273 (serves faroedu.com), linked to this repo: branch main, publish directory ".", no build command. Every commit to main deploys.

## Editing rules (from Abram)

- Say machine learning, never "AI".
- Faro drafts; the teacher decides what is taught next. Never "writes what to teach next".
- Compass is built on the research behind computer-adaptive assessment. Never "built by psychometricians".
- No standard codes, no counts, no efficacy numbers, no testimonials until real, no pricing section.
- Faro Brain = capture, articulate, reconcile, expand, aggregate.
- Photos are free-license Unsplash stand-ins; replace with pilot-district photography (with releases).
